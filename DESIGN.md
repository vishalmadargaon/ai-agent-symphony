# AI Agent Symphony Biome Design System

## Core Aesthetic: 3D Twin Biome
The visual signature of this system is a 3D twin biome that blends organic growth patterns with futuristic software architectures. It uses high-contrast translucency, 3D radial depth, noise overlays, and floating neon particles to represent live data orchestration.

### Color Palette (Biome Mode)
- **Base Canvas Background**: `#030307` (Void Black with CSS noise overlays)
- **Liquid Glass Panel Fill**: `rgba(15, 23, 42, 0.4)` (Deep slate with 40% opacity and high blur)
- **Inner Glass Border**: `rgba(255, 255, 255, 0.1)` (1px solid semi-transparent boundary)
- **Trigger Node Glow**: Neon Lime (`#84cc16` / `rgba(132, 204, 22, 0.4)`)
- **Agent Node Glow**: Neural Cyan (`#06b6d4` / `rgba(6, 182, 212, 0.4)`)
- **Output Node Glow**: Cyber Pink (`#ec4899` / `rgba(236, 72, 153, 0.4)`)
- **Text Layers**: Primary Slate-50 (`#f8fafc`), Muted Slate-400 (`#94a3b8`)

### Typography
- **Headlines / Statuses**: `Space Grotesk` (technological, geometric sans)
- **Inputs / Details**: `Geist` or `Inter` (high legibility workspace font)

### Layout & Borders
- **Border Radius**: 16px rounded corners (`rounded-2xl`) for biome cards and nodes.
- **Backdrop Blur**: `24px` (`backdrop-blur-xl` / `backdrop-blur-2xl`) for ultimate depth.
- **Edge Connections**: Glowing, fluid neon tendrils with active SVG dash-offsets showing moving data packets.
